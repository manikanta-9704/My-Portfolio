# Allu Manikanta — Portfolio Website

A responsive portfolio website built with **HTML5, CSS3, and Bootstrap 5**. Custom CSS and a small JavaScript file are included for interactions and 3D-inspired effects. No React or other frontend framework is used.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. For best results, keep an internet connection for the Bootstrap CDN and Google Fonts.

You can also open the folder in VS Code and use Live Server if you have it installed.

## Customize before publishing
Search `index.html` for these placeholders and update them:
- `your.email@example.com` — replace with your email.
- `Add your GitHub profile` — replace the link and label with your GitHub profile.
- `Add your LinkedIn profile` — replace the link and label with your LinkedIn profile.
- `ADD LINK` — replace with each project's GitHub/demo link.
- Internship company name and any missing experience details.
- Update project descriptions, skill levels, and timeline details as needed.

## Project cards
Six cards are included for:
1. Expense Tracker
2. Student Management System
3. AI Blind Assistant
4. Blood Donation Web Application
5. Quiz Application
6. To-Do List

To add another card, copy one `<div class="col-md-6 col-xl-4"> ... </div>` project column inside the projects section and update its content.

## Technologies
- HTML5
- CSS3 (custom styling, responsive layout, 3D-inspired transforms and animations)
- Bootstrap 5.3.3 (via CDN)
- Vanilla JavaScript (card tilt, cursor glow, active nav, mobile menu close)

## Notes
- The contact section is a visual contact area; it does not submit a backend form.
- 3D effects are CSS-based and designed to work without a 3D library.
